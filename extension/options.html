JevLens 設定

TypeSafe Jev

直接連線：https://api.typesafe.ai/v1/systemone，模型 jev-latest。API key 儲存在 chrome.storage.local，不會同步到 Chrome Sync。

注意：把 API key 存在 Extension 代表它不是機密。能讀取你的 Extension profile / storage 或具備足夠本機權限的程式，都可能取得這把 key。

圖片分析

圖片先在 Chrome 內用內建多模態 Prompt API 做固定 schema 的視覺特徵抽取；若瀏覽器支援，也會嘗試文字偵測與 QR code。原始圖片不會送到 TypeSafe，Jev 只收到 alt / OCR / 固定視覺 signals。

首次啟用內建模型可能需要額外下載。若你的 Chrome/裝置不支援，JevLens 仍會使用圖片 alt、尺寸、可用的 OCR/QR 與低權重 pixel signals。

分類邊界

政治傾向是描述性訊號，不是可信度或價值評分；政治分類只描述可見文字的內容與 framing；「流量操作」只表示可觀察的 click / engagement optimization 訊號。單篇內容無法證明作者動機、協同操弄或內容真假。
